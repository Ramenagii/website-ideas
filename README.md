# Website Ideas

Hackathon-ready website and app concepts, refined into focused MVPs with demo hooks, judging angles, and next build steps.

## What This Repo Is

This started as an hourly website-ideas backlog. It is now shaped for hackathons: each concept should be small enough to demo in a weekend, useful enough to explain in one sentence, and polished enough to ship as a public project.

## Start Here

- `ideas/website-ideas.md` - the idea backlog, now upgraded with hackathon positioning.
- `generated/HACKATHON_PLAYBOOK.md` - the strongest concepts, ranked and scoped for demos.
- `generated/` - practical product drafts for each concept.
- `automation/` - notes and prompts for future automation runs.

## Best Hackathon Bets

1. `receipts-warranty-vault` - obvious pain, strong AI/OCR demo, useful export packet.
2. `move-out-checklist` - clear before/after story, photo proof, renter-friendly PDF.
3. `meal-planner-grocery-list` - highly demoable, local-first, instant grocery aggregation.
4. `freelance-invoice-client-portal` - practical business value with payments or mock checkout.

## Hackathon Quality Bar

Every idea should have:

- A 30-second problem statement.
- A click-through demo with seeded data.
- One "wow" moment: OCR, AI summary, PDF export, offline mode, or one-click share.
- A realistic MVP that can be built without pretending to be a full company.
- A clear judging story: impact, technical execution, design polish, and future potential.
