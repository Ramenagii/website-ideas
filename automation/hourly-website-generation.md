# Hourly Website Generation

## Goal

Every hour, read `ideas/website-ideas.md`, choose the next unchecked idea, and generate or refine a website draft in `generated/`.

## Expected Output

- A folder inside `generated/` named after the idea.
- A short implementation summary.
- Any follow-up tasks added back to the idea entry.

## Prompt

Read the next unchecked website idea from `ideas/website-ideas.md`. Create a practical website draft for it, keeping the implementation small, usable, and easy to continue later.
